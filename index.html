    How it works

    1. Hybrid AI. Every request goes through Firebase AI Logic with PREFER_ON_DEVICE. Chrome's built-in Gemini Nano answers when it's available; otherwise the SDK falls back to Gemini in the cloud. Each result shows where it ran and how long it took.
    2. Structured output. Listings come back as JSON constrained by one schema (on-device responseConstraint, cloud responseSchema), so categories and conditions are always valid.
    3. Offline first. Listings are stored on the device and synced to Firestore (anonymous Auth) when you're online. Photos never leave the device unless cloud inference is needed.
    4. Remote Config sets the cloud model, currency and writing style; App Check protects the Gemini API.
